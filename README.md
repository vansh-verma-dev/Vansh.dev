## ✨ About the Project

## ⚙️ Getting Started

### Prerequisites

Make sure you have installed:

- [Node.js](https://nodejs.org/)
- npm
- A MongoDB Atlas account or local MongoDB instance

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd VanshDev
```

### 2. Install frontend dependencies

```bash
cd frontend
npm install
```

Start the frontend:

```bash
npm run dev
```

### 3. Install backend dependencies

Open another terminal from the project root:

```bash
cd backend
npm install
```

### 4. Configure environment variables

Create a `.env` file inside the `backend` directory:

```env
PORT=3000
MONGO_URI=your_mongodb_connection_string
```

Replace the placeholder with your own MongoDB connection string.

**Security:** Never commit `.env` or expose your database credentials publicly.

### 5. Start the backend

From the `backend` directory, run:

```bash
node server.js
```

Check your server's configured URL to verify that the backend is running.
